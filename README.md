# QR Anything

*Give me a Quick Response!*

A tiny, privacy-friendly web app that turns text, links, Wi-Fi credentials, contacts and more into a styled, brandable QR code — entirely in your browser. No files or data are ever uploaded to a server.

**Live at:** [qr.michels.world](https://qr.michels.world)

## Features (v0.1.0)

- **Content types:** plain text, links, Wi-Fi network (SSID/password/encryption/hidden), vCard contact, e-mail, phone call, SMS
- **Styling:** dot shape (square, circles, rounded, classy, extra-rounded), corner shape, code color, background color
- **Logo in the center:** upload an image to embed in the middle of the code. Error correction is automatically forced to "High" and the logo is capped at 28% of the code area so the code stays scannable
- **Background image:** place an image behind the code with an adjustable visibility slider (0–100%)
- **Scan test:** a software-only check (no camera needed) that decodes the generated image right in the browser via jsQR and confirms it still matches the original content
- **Frame:** a simple border around the code with adjustable color, thickness, corner radius and padding
- **Title:** optional text above, below, left or right of the code (fixed font for now — font choice is planned for a later version)
- **Automatic platform-logo detection:** if the content links to a known platform (Instagram, YouTube, TikTok, Facebook, X, WhatsApp, LinkedIn, Spotify, GitHub, Pinterest, Snapchat, Threads), a small brand logo is placed next to the title automatically. Can be switched off per code
- **Export:** PNG and JPG (full composition including frame/title/background). SVG export is available for the plain styled QR code itself (frame/title/background compositing is raster-only for now — see "On the horizon")
- Settings (style, frame, title, etc.) are remembered locally between visits
- Installable as a PWA with offline support
- Dark mode by default, with a light mode toggle
- 100% client-side: no backend, no analytics, no tracking

## How it works

The QR module pattern itself is generated by the vendored [qr-code-styling](https://github.com/kozakdenys/qr-code-styling) library (dot/corner shapes, colors, center logo, error-correction handling). The result is drawn onto an in-memory `<canvas>` together with the optional background image, frame and title, which are composited manually. The scan test decodes that same canvas with the vendored [jsQR](https://github.com/cozmo/jsQR) library — a pure image-processing decode, not a camera — and compares the result against the original input.

Automatically detected platform logos use icon files vendored from the [Simple Icons](https://simpleicons.org/) project. Brand logos are shown unmodified, at a fixed small size, solely to indicate which platform a code links to (nominative use) — no endorsement by the platform is implied.

## Browser support

Works in all modern browsers (Chrome, Safari, Firefox, Edge). Requires `<canvas>`, `FileReader` and `Promise` support, all standard in current browsers.
